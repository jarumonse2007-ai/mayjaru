Servicios y notificaciones

Aprende cómo las aplicaciones realizan tareas y mantienen informado al usuario.

¿Qué son los servicios y las notificaciones?

Los servicios permiten que una aplicación realice determinadas tareas sin depender directamente de una pantalla abierta. Las notificaciones son mensajes que informan al usuario sobre eventos o actualizaciones.

Características principales

Actividad

Permiten realizar tareas en segundo plano cuando corresponde.

Comunicación

Informan sobre eventos importantes.

Actualización

Ayudan a mantener informado al usuario.

Organización

Gestionan tareas y avisos de la aplicación.

Tipos de servicios y notificaciones

1. Servicios en primer plano

Realizan tareas que el usuario puede identificar, como reproducir audio.

2. Trabajo en segundo plano

Permite ejecutar tareas programadas o diferibles.

3. Notificaciones locales

Se generan desde el propio dispositivo.

4. Notificaciones push

Se envían desde un servidor mediante un servicio de mensajería.

¿Cómo funcionan?

01. Evento

Ocurre una acción o se programa una tarea.

02. Procesamiento

La aplicación gestiona el evento.

03. Generación

Se prepara una notificación si es necesario.

04. Aviso

El usuario recibe la información.

Herramientas y tecnologías

WorkManager

Administra tareas que pueden ejecutarse de manera diferida.

NotificationManager

Permite administrar las notificaciones del sistema.

Firebase Cloud Messaging

Permite enviar mensajes y notificaciones a dispositivos.

Ejemplos de uso

  • Recordatorios de tareas.
  • Avisos de mensajes recibidos.
  • Actualizaciones de aplicaciones.
  • Reproducción de música.

Importancia

Los servicios y las notificaciones permiten mejorar la comunicación entre una aplicación y sus usuarios, además de facilitar la realización de tareas programadas.
