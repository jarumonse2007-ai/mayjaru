TEMA 01 · DESARROLLO MÓVIL

Control de versiones

Organiza, administra y controla los cambios realizados durante el desarrollo de una aplicación.

Comenzar a aprender ↓
01 · CONCEPTO

¿Qué es el control de versiones?

⌘

Historial de versiones

Organiza, registra y recupera los cambios de tu proyecto.

v1.0 → v2.0

Es un sistema que permite registrar y administrar los cambios realizados en los archivos de un proyecto. Facilita recuperar versiones anteriores, comparar modificaciones y trabajar en equipo.

Ejemplo de historial de versiones

Así se registran los cambios de un proyecto a lo largo del tiempo:

01

Versión 1.0

Se crea el proyecto inicial.

02

Versión 1.1

Se agregan nuevas funciones.

03

Versión 2.0

Se realizan mejoras importantes.

02 · CARACTERÍSTICAS

Características principales

📚

Historial

Registra los cambios realizados en el proyecto.

🔄

Recuperación

Permite volver a versiones anteriores.

👥

Colaboración

Facilita el trabajo entre varios desarrolladores.

🔍

Comparación

Permite identificar las diferencias entre versiones.

03 · CLASIFICACIÓN

Tipos de control de versiones

Centralizado

Utiliza un servidor central donde se almacena el historial del proyecto. Los usuarios trabajan conectándose a ese servidor.

Distribuido

Cada desarrollador cuenta con una copia completa del historial del proyecto. Permite trabajar localmente y sincronizar los cambios.

04 · FUNCIONAMIENTO

¿Cómo funciona?

1

Crear un proyecto

Se prepara la carpeta con los archivos del proyecto.

2

Registrar cambios

Se guardan las modificaciones realizadas.

3

Crear versiones

Se registra un historial de los avances.

4

Compartir y recuperar

Se sincronizan los cambios o se recuperan versiones.

05 · HERRAMIENTAS

Ejemplos de herramientas

Git

Sistema distribuido para administrar versiones.

GitHub

Plataforma para alojar y colaborar en proyectos Git.

Subversion

Sistema de control de versiones centralizado.

06 · IMPORTANCIA

¿Por qué es importante?

El control de versiones ayuda a mantener organizado el código, evitar la pérdida de avances, detectar errores y facilitar la colaboración. Es especialmente útil en proyectos de desarrollo de aplicaciones móviles.
